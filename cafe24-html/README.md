# Cafe24 상세페이지 HTML — 붙여넣기 방법

1. Cafe24 관리자 → 상품관리 → 상품 선택
2. **상품 상세설명** 에디터 열기
3. 툴바에서 **`HTML`** 버튼 (또는 `소스` / `< >`) 클릭 → HTML 편집 모드 전환
4. **기존 내용 맨 아래로 커서 이동** (기존 이미지 태그는 절대 지우지 말 것)
5. 해당 제품의 html 파일 내용을 **전체 복사해서 맨 끝에 붙여넣기**
6. 저장

## 파일 대응

| 파일 | 제품 |
|---|---|
| `01-뱀부포레스트-캔들.html` | 르버덴 뱀부 포레스트 센티드 캔들 |
| `02-부시맨캔들-캔들.html` | 르버덴 부시맨 캔들 센티드 캔들 |
| `03-샤먼-캔들.html` | 르버덴 샤먼 센티드 캔들 |
| `04-밸리오브로지즈-캔들.html` | 르버덴 밸리 오브 로지즈 센티드 캔들 |
| `05-차콜디톡스-바솝.html` | 르버덴 뱀부 포레스트 차콜 디톡스 바 솝 |
| `06-미르프로텍션-바솝.html` | 르버덴 부시맨 캔들 미르 프로텍션 바 |

## 주의

- **이미지를 지우지 않는다.** 이미지는 사람이 보고, 이 텍스트는 검색엔진과 AI가 읽는다.
- 폰트는 Pretendard 우선, 없으면 시스템 고딕으로 대체된다.
- 모바일에서도 읽히도록 max-width 760px, 좌우 여백 24px로 잡았다.
- Cafe24 에디터가 인라인 스타일을 지우는 경우가 있으니, 저장 후 실제 페이지에서 한 번 확인할 것.
