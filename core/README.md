# core/ — 제품별 코어 사실 원장

시장·채널·컨셉과 무관하게 **항상 같아야 하는 사실**만 담는 파일들이다.
마케팅 표현, 카피, 무드는 여기에 넣지 않는다 (그쪽은 `core-facts/core-facts.yaml`).

## 원칙

1. **추측한 값은 넣지 않는다.** 확인하지 못한 항목은 `확인 필요`로 남긴다.
2. **항목마다 출처를 적는다.** 출처 없는 값은 없다.
3. **환산값을 실측값처럼 쓰지 않는다.** (예: 250g → 8.82oz 계산은 되지만, 라벨 인쇄값이 아니면 안 쓴다)
4. 공통 사실은 공통 파일에만 둔다. 제품 파일에 중복 기재하지 않는다.

## 파일 구조

| 파일 | 내용 |
|---|---|
