# 캔들 화기 안전 표시 — 미국 · EU · 한국

- 작성: 2026-09-19
- 대상: 캔들 4종 (뱀부 포레스트 · 부시맨 · 샤먼 · 밸리 오브 로지즈)
- 성격: **일반 규제 지식 기반 정리.** 다니엘 스톤이나 손용석 대표처럼
  직접 서류를 받은 게 아니라, 업계 표준 규정을 조사해 정리한 것이다.
  최종 확정 전 **변호사/규제 컨설턴트 검토 권장.**

⚠️ 이 문서는 "등록 완료"가 아니라 **등록에 필요한 문구·기준을 준비한 것**이다.
   미국은 자율 표시(제3자 등록 기관 없음), EU/한국은 실제 제출·신고 절차가
   별도로 있고 대행사가 필요할 수 있다. 아래 "다음 단계" 참조.

## 1. 미국 — ASTM F2417 (자율 표준, 정부 등록 없음)

미국은 캔들 화재 안전에 대한 **연방 정부 등록 제도가 없다.** 업계 표준
`ASTM F2417 (Standard Specification for Fire Safety for Candles)`을
자율적으로 준수하고, 그 표준이 요구하는 경고 문구를 라벨/박스에 표시하면 된다.
CB2 등 리테일러가 요구하는 Intertek 화재 테스트도 이 표준 기준이다.

### 필수 표시 문구 (ASTM F2417 표준 문안)

```
WARNING: NEVER LEAVE A BURNING CANDLE UNATTENDED.
KEEP AWAY FROM CHILDREN AND PETS.
KEEP AWAY FROM THINGS THAT CATCH FIRE.
```

### 권장 추가 사항 (업계 관행)

- 첫 사용 시 표면 전체가 녹을 때까지 태울 것 (터널링 방지) — leverden 사용법에 이미 포함
- 심지를 3~5mm로 자를 것 — leverden 사용법에 이미 포함
- 화기 근처(커튼, 가구)에서 최소 안전거리 유지
- 유리 용기의 약 1cm(2.5cm 권장) 잔여 왁스 시점에 사용 중단 — leverden은 이 문구를 이미 삭제하기로 결정했음 (`core-facts.yaml` 참조), 화재 안전 관점에서는 재검토 여지 있음 → `확인 필요`

**leverden 현재 사용법 문구와 비교**: 첫 사용/심지 자르기 항목은 이미 충족.
"불 켠 채 자리 비우지 말 것", "어린이·반려동물 접근 금지"도 KR 페이지에
이미 있음 (`core/shaman.md` 등 참조).

✅ **미국 — 확인 완료 (2026-09-19, 소영님)**: 실물 라벨에 화기 안전 경고
문구가 **이미 부착돼 있음.** 추가 조치 불필요.

## 2. EU — CLP 규정 (EC) No 1272/2008 + 일반제품안전규정(GPSR)

EU는 향료 성분에 따라 **CLP(분류·표시·포장) 규정**상 위험 문구(H-statement)와
예방 문구(P-statement)를 표시해야 할 수 있다. 캔들 자체보다는 **향료
컴파운드의 CLP 분류에 따라 결정**된다.

### 확인 필요 사항

| 향료 | 확인된 위험 분류 | 근거 |
|---|---|---|
| `BAMBOOM CANDLE 28` (IFF, 뱀부 캔들) | Flammable liquids Cat 4, Skin irritation Cat 2, Eye irritation Cat 2A, Skin sensitisation Cat 1, Carcinogenicity Cat 2, Reproductive toxicity Cat 2 | SDS (IFF, 2021-06-21) |
| 나머지 3종 향료(Olifir Bougie XII·Spiritual Wood·Chemia) | **확인 필요** — 각 SDS의 Section 2(GHS 분류) 재확인 필요 | — |

🔴 뱀부 캔들 향료(BAMBOOM CANDLE 28)의 SDS에 **H317(알레르기성 피부 반응 유발 가능)**,
**H351(발암 의심)**, **H361(생식능력 손상 의심)** 경고문구가 명시돼 있다.
이건 향료 원액(컴파운드) 자체 취급 시 경고이지, 완제품 캔들에 그대로
적용되는 건 아니다 — 캔들에 들어간 후 희석 농도 기준으로 최종 제품의
CLP 분류를 다시 계산해야 한다 (혼합물 분류 규칙, CLP Annex I 적용).

**EU 알레르겐 표시**: 뱀부 캔들 향료의 오크모스(Oakmoss) 1.218% 함유가
확인됨 — Reg. 2023/1545 확대 알레르겐 목록(81종) 표시 대상 여부 확인 필요
(향초/캔들은 코스메틱이 아니라 GPSR 적용 대상이라 화장품 알레르겐 표시
의무와는 다른 체계일 수 있음 — 법률 검토 필요).

### 다음 단계 (EU)

1. 4개 향료 전부의 최신 SDS Section 2/3 재확인 → 완제품 희석 농도 기준
   CLP 재분류
2. 완제품에 위험 문구 표시가 필요한지 EU 규제 컨설턴트에 확인
3. 다니엘 스톤이 이미 경고한 "향료별 독성학자 검토 + 지역별 SDS" 요건과
   같은 선상의 작업 — `docs/규제-확인.md` 참조

## 3. 한국 — 화학제품안전법 / 생활화학제품

✅ **확인 완료 (2026-09-19, 소영님)**: **향초(캔들) 5종 + 디퓨저 1종**이
"안전확인대상생활화학제품"으로 **이미 신고돼 있음** (대행사 **일도깨비**).
디퓨저 쪽 신고번호는 확보됨(`HB25-12-0057`, 유효기간 2028-01-20). 캔들
5종의 개별 신고번호·유효기간은 아직 문서에 없음 → `확인 필요`
(일도깨비 쪽에 캔들 신고증명서 사본 요청해서 이 문서에 기록할 것).

### 다음 단계 (한국)

1. 캔들 신고증명서 사본 확보해서 신고번호·유효기간을 이 문서와
   `core/_공통-캔들.md`에 기록 (아래는 참고용으로 남겨둠, 실제로는 해결됨)
   확인 가능
2. 대상이면 디퓨저와 동일한 절차(신고증명서 + 확인결과서 + 라벨 가이드)
   진행
3. 대상이 아니면 소방청 고시 등 다른 규정 적용 여부만 확인

## 종합 — 무엇이 실제로 "등록"이 필요한 항목인가

| 지역 | 등록/신고 필요 여부 | 현재 상태 |
|---|---|---|
| 미국 | 정부 등록 없음 (자율 표준 준수만) | ✅ 완료 — 실물 라벨에 이미 부착됨 |
| EU | 등록 제도 없음, 다만 CLP 표시 의무는 있을 수 있음 | 향료 4종 CLP 재분류 필요 |
| 한국 | 안전확인대상생활화학제품 신고 | ✅ 완료 — 캔들도 이미 신고돼 있음(2026-09-19 확인). 신고번호·유효기간만 문서화 필요 |

🔴 **제가 직접 정부 기관에 신고를 제출할 수는 없습니다.** 한국 쪽은
일도깨비 같은 대행사를 통해 실제 신고를 진행해야 하고, EU 쪽은 CLP
재분류 결과에 따라 컨설턴트 확인이 필요합니다. 이 문서는 그 절차를
시작하기 위한 사전 조사이며, 실제 제출은 소영님(또는 대행사)이
진행하셔야 합니다.
