## 페루산 팔로 산토 스틱 단품 판매 (2026-09-19)

로고를 박은 팔로 산토 스틱을 별도 상품으로 판매하는 아이디어.

- 배경: 샤먼 캔들 원료 확인 과정에서, leverden이 현재 실제 팔로 산토
  원료를 다루는 공급망이 없다는 게 확인됨 (향료는 조합 향료).
- 체크할 것 (실행 전):
  - 페루산 팔로 산토 공급처 신규 발굴 (지속가능 채취 증빙 포함)
  - 페루 수출 서류 (SERFOR 등)
  - 미국/한국 반입 시 식물 원료 수입 규정 (APHIS, 농림축산검역본부 등)
  - CITES 비대상 확인 (`Bursera graveolens` 기준, 다른 종은 규제 대상일 수 있음)
