# 1. 기계용 파일 3종 — `agents.md` / `llms.txt` / `.well-known/ucp`

## 결과: **세 개 다 없다**

현재 운영 테마 **`28/08 - Romane`** (MAIN, 최종수정 2026-01-01) 의 파일 목록을
`llms` · `agents` · `ucp` · `well-known` 패턴으로 조회한 결과 **일치 파일 0건**이다.

| 파일 | 상태 | 비고 |
|---|---|---|
| `/agents.md` | ❌ 없음 | 테마에 해당 파일 없음 |
| `/llms.txt` | ❌ 없음 | 테마에 해당 파일 없음 |
| `/.well-known/ucp` | ❌ 없음 | 테마에 해당 파일 없음 |

### 구조적 제약 — Shopify에서는 그냥 올릴 수 없다

Shopify는 **루트 경로(`/llms.txt`)에 임의 파일을 올리는 기능이 없다.**
파일을 올리면 `cdn.shopify.com/...` 로 서빙되지 `leverden.co/llms.txt` 가 되지 않는다.

가능한 방법은 두 가지뿐이다:

| 방법 | 설명 | 난이도 |
|---|---|---|
| **템플릿 + 리다이렉트** | `page.llms.liquid` 템플릿을 만들고 `/llms.txt` → 해당 페이지로 URL 리다이렉트 | 중 |
| **앱 프록시** | 앱이 `/.well-known/*` 등 경로를 가로채 응답 | 높음 |

⚠️ **`.well-known/ucp` 는 특히 어렵다.** Shopify 리다이렉트는 `.well-known` 경로를
   다루기 까다로워 앱 프록시가 사실상 유일한 길이다.
   → 🟡 **하기로 결정하기 전에 실현 가능성부터 확인할 것.** `확인 필요`.

📌 다만 현재 테마에 파일이 없다는 것은 확실하므로, **앱 프록시를 따로 붙이지 않았다면
   세 경로 모두 404 일 것이다.** 브라우저로 한 번만 열어보면 확정된다.
