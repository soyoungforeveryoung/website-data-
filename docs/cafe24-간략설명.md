# 톤 규칙

레퍼런스 네 브랜드의 공통점을 규칙으로 정리한다.

| 규칙 | 설명 |
|---|---|
| **무드를 단어 하나로 앞세운다** | `RELAXATION` `ENERGY` `PURIFICATION` `SELF-LOVE` |
| **장소·원료·사실을 말한다** | 효능, 기분, 권유를 말하지 않는다 |
| **설명하지 않는다** | "~에서 영감을 받아 만든 향입니다" 같은 해설을 붙이지 않는다 |
| **문장을 짧게 끊는다** | 명사로 끝나는 문장을 섞는다. `~입니다`를 반복하지 않는다 |
| **평서형을 쓴다** | `씻는다`, `자란다`. 과한 경어체는 거리를 만든다 |
| **노트는 가운뎃점으로 나열** | 문장에 섞지 않는다 |
| **사양은 맨 아래 한 줄** | 본문과 섞지 않는다 |

⛔ 금지: 느낌표, `~해보세요`, `특별한`, `완벽한`, `힐링`, `럭셔리`

# 표현 원칙

| 항목 | 원칙 |
|---|---|
| 힘바족 | 제약이 아니라 **환경에 적응한 방식**으로. "못하게 해서"가 아니라 "연기로 씻는다" |
| 정화 | **무드로만.** 공기 정화·살균·탈취 금지 |
| 디톡스 | 제품명은 유지. 본문에서 **독소·해독** 표현 금지. 뜻은 '차콜의 딥 클렌징' |
| 프로텍션 | 제품명은 유지. **힘바족의 전통적 사용**이라는 문화적 맥락으로만. 피부 보호 '효과' 금지 |
| 직접 수급 | **미르 프로텍션 바**에만 "직접 받는다". 캔들은 **"나미비아에서 온다"**까지만 |
