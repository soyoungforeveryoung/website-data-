# 표현 원칙 (반드시 지킬 것)

| 항목 | 원칙 |
|---|---|
| 힘바족 서술 | 제약이 아니라 **환경에 적응한 지혜**로. "못하게 해서"가 아니라 "물 대신 연기로 씻는 방법을 지켜 왔다" |
| 정화(Purification) | **정서적 무드로만.** 공기 정화·살균·탈취 등 기능 주장 금지 |
| 직접 수급 | 현재는 **미르 프로텍션 바에만** 사용. 캔들은 향료 확인 전까지 '영감'으로만 |
| 효능 | 모든 문안이 "~한 시간을 위해 만들었습니다"로 끝난다. 효능이 아니라 사용 상황 제안 |
