# Cafe24 상품간략설명 — 복사용 원고

**넣는 곳**: 상품관리 → 상품 목록 → 제품 선택 → **상품 간략설명** 칸
**효과**: 이 칸 하나가 세 곳에 동시에 반영된다.
1. JSON-LD `description` (AI·검색엔진이 읽는 유일한 제품 정보)
2. 제품명 아래 회색 설명
3. 기본정보 표

**방침(A안)**: 기존 "교환/반품 불가" 안내를 **완전히 빼고** 제품 설명만 넣는다.
반품 규정은 상세페이지 하단 또는 별도 고지 영역으로 옮긴다.

**작성 원칙**: 향 → 목적 → 사양 순. 효능 주장 없음. 사용 상황 제안으로 마무리.
근거: `core-facts/core-facts.yaml`, `docs/collections.md`, `docs/usable-facts.md`

## 옵션명에 들어간 제품코드 오류

밸리 오브 로지즈 옵션명에 다른 제품 코드가 노출되어 있다.
```
현재: 르버덴 밸리오브로지즈 센티드 캔들 250g (P000000S000B)
                                          ↑ 부시맨 캔들 코드
수정: 르버덴 밸리 오브 로지즈 센티드 캔들 250g
```
제품명에 코드를 노출할 이유가 없으므로 괄호째 삭제한다.
