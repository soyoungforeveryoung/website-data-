## 성분 표기 방식 — Fragrance / Parfum으로 통일

바 솝 2종의 향료 표기 방식이 서로 달라 통일이 필요하다.

| 제품 | 현재 표기 |
|---|---|
| Charcoal Detox Bar | `Fragrance/Parfum` 없이 라벤더·베르가못·패츌리 **에센셜 오일 개별 나열** |
| Myrrh Protection Bar | `Fragrance (parfum)` |

**결론: `Fragrance` (미국) / `Parfum` (EU·INCI) 표기가 가능하며, 이쪽으로 통일한다.**

- 조향사가 만든 향료 조성물이므로 `Parfum`이 정확한 표기다.
  에센셜 오일을 개별 나열하면 단일 오일만 쓴 것처럼 오해될 수 있다.
- ⚠️ **단, 기준치를 넘는 알레르기 유발성분은 `Parfum`으로 묶어도 별도 표기해야 한다.**
  - EU: 리브온 10 ppm / 린스오프 100 ppm 이상
  - 한국: 식약처 고시 25종, 리브온 0.001% / 린스오프 0.01% 초과
  - 미국: `Fragrance` 표기 허용 (21 CFR 701.3)
- 두 제품의 표기 방식을 반드시 동일하게 맞춘다.
  (Charcoal Bar 성분표에는 `Fragrance/Parfum` 없이 라벤더·베르가못·패츌리 **에센셜 오일**이
   직접 기재되어 있다. Myrrh Bar에는 `Fragrance (parfum)` 표기가 있다. 서로 방식이 다르다.)

# 2. Oakmoss — 바디 향료에만 있다

향료 노트와 배합은 **소영님이 조향사와 직접 논의해 만든 것**이며,
향료 서류도 소영님이 직접 관리한다. 향에 관한 사항은 소영님 확인이 원본이다.
아래는 그 내용을 서류로 뒷받침한 것이다.

오크모스는 캔들이 아니라 바디 향료에 들어 있다.

`BAMBOOM 34 LATEST` (Bamboo Forest **바디**) 알레르겐 선언서 (IFF, 2021-08-17, Doc ID 1306252)

| 알레르겐 | CAS | 향료 원액 내 함량 |
|---|---|---|
| **Evernia Prunastri (Oakmoss) Extract** | 68917-10-2 / 90028-68-5 | **1.218 %** |
| Limonene | 5989-27-5 | 4.015 % |
| Linalool | 78-70-6 | 1.747 % |
| Geraniol | 106-24-1 | 0.045 % |
| Citronellol | 106-22-9 | 0.003 % |
| Eugenol | 97-53-0 | 0.003 % |
| Citral | 5392-40-5 | 0.002 % |
| Benzyl Alcohol | 100-51-6 | 0.001 % |
| Farnesol | 4602-84-0 | 0.001 % |
| Evernia Furfuracea (Treemoss) Extract | — | 불검출 |

→ **캔들 향료(Bougie XII, Spiritual Wood, Coriander 78296) 문서에는 오크모스가 나오지 않는다.**
→ 사이트에서 캔들 설명에 오크모스가 등장한 것은 **바디 라인 정보가 섞여 들어간 것**이다.

### 표시 의무 계산 (검증 필요)

EU 기준 알레르겐 표시 의무: 리브온 10ppm 이상, 린스오프 100ppm 이상.

바디 제품(린스오프, IFRA Cat 9)에 최대 배합률 2.1%로 넣었다고 가정하면

| 알레르겐 | 완제품 농도 | ppm | 표시 의무 |
|---|---|---|---|
| Limonene | 0.0843 % | 843 | **표시 필요** |
| Linalool | 0.0367 % | 367 | **표시 필요** |
| **Oakmoss** | 0.0256 % | 256 | **표시 필요** |
| Geraniol | 0.00095 % | 9.5 | 불필요 |

⚠️ 위는 **최대 배합률 기준 추정**이다. **실제 배합률을 확인해야 확정된다.**
⚠️ Oakmoss(Evernia prunastri) 자체는 EU 화장품규정 Annex III 제한 물질이며,
   완제품 0.1% 상한이 있다. 위 추정치(0.0256%)는 상한 이내다.

## 알레르겐 선언서

`BAMBOOM 34` 알레르겐 선언서는 **2021년 8월 17일자**이며,
**EU 화장품규정 개정 이전의 26종 알레르겐 목록** 기준이다.

→ Reg (EU) 2023/1545로 표시 대상 알레르겐이 대폭 확대되었다.
→ 2021년 서류로는 현행 EU 라벨을 만들 수 없다. **재발급 필수.**
→ 시행 시점과 유예기간은 **EU RP(책임자)에게 확인할 것.**
   메일함에 이탈리아 CPNP/RP 담당 **조경상**님 연락처가 있다 (tradeit.cho@gmail.com, 2026-05-27).

  → **배합률 관련 자료일 가능성이 있다.** 미확인 상태이므로 열어볼 것.

---

## ✅ 알레르겐 선언서 — 전부 보유

`소영` 확인 (2026-09-13): **알레르겐 선언서는 6개 제품분 모두 메일함에 있다.**
추가 요청 불필요. 향료사에 메일을 더 보내지 않는다.

⚠️ 단, **문서마다 기준 규정 버전이 다를 수 있다** (26종 구판 vs `Reg 2023/1545` 81종).
   표시문구를 확정하기 전에 각 파일의 기준 버전을 눈으로 확인할 것.
   확인된 것: `OLIFIR V4i` = 81종 최신본.

---

⚠️ 향료사들은 **전체 성분 목록(full ingredient list)은 영업비밀로 공개하지 않는다.**
   제공 가능한 것은 **IFRA 인증서 · 알레르겐 선언서 · SDS** 세 가지다.
   서류 요청 및 수령은 소영님이 직접 관리한다.
